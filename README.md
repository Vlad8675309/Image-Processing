# Image Processing

This is a C++ application that provides basic image processing and drawing for grayscale images.

### Description

The program provides 3 main image processing operations: brightness & contrast adjustment, gamma correction and image convolution (blur and edge detection). Below is an example of the edge detection operation applied on an image of the Mona Lisa.
